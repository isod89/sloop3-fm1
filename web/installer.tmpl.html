Install SLOOP 3 on your FM-1

SLOOP 3 turns the M-VAVE FM-1 into a complete groovebox: drums, bass, chords, melodies and effects, with a sequencer that loops it all. This page installs it for you, step by step, right from your browser.

  • About 10 minutes the first time, 1 minute to update
  • A full backup before anything is written
  • Nothing to install on your computer
Step 1 of 5

Before you start

SLOOP 3 is new. Here is what to expect, and what you need.

SLOOP 3 is a public betaIt was rewritten from scratch: a new sound engine, a new sequencer, a new interface. It is being tested on real FM-1s right now, so you may meet bugs. Keep backups, and don't rely on it on stage yet. When something goes wrong, tell us: every report makes it better.
Prefer the tried and tested version?SLOOP 2.8 stays available on its own page: isod89.github.io/sloop-fm1. SLOOP 3 never changes SLOOP 2.8's data, so you can go back at any time with your backup.

You need

  • An M-VAVE FM-1 and a USB data cable (a charge-only cable won't work), plugged straight into the computer.
  • Chrome or Edge on Windows, macOS, Linux or ChromeOS (or Chrome on Android).
  • The FM-1 powered by USB the whole time.
Updating from SLOOP 3.0 to 3.3.4?Since 3.3.5 the FM-1 keeps one project, with room for the fullest one. At the first start, the newest of your 8 projects is kept. Before you install: open the web editor, Projects, BACK UP EVERYTHING. The editor puts any of them back later.
The whole install: about 10 minutes the first time.
Step 2 of 5

The safety net: m-bootloader

SLOOP 3 installs through m-bootloader, a small free program that sits under the firmware. If an install is ever interrupted, your FM-1 opens a recovery menu instead of getting stuck. You set it up once.

Is it already there? Check in 10 seconds

  1. Switch the FM-1 off.
  2. Hold PLAY and switch it on. Keep holding about a second.
  3. A menu with BOOT APP, DOWNLOAD MODE and MIDI MODE? Then it's there.
Recommended · Windows, macOS, Linux

With M-Flasher

M-Flasher ↗m-bootloader (fm1-uboot.boot) ↗
  1. Download M-Flasher and fm1-uboot.boot (links above). Windows: run M-Flasher.exe as administrator (it isn't signed: More info → Run anyway). macOS: System Settings → Privacy & Security → Open Anyway.
  2. Connect the FM-1 and click DOWNLOAD MODE in M-Flasher (or, with SLOOP 2.8 running, hold OCT- and OCT+ for 5 seconds). The screen doesn't change; the computer sees a disk named WL82 UBOOT1.00. If Windows offers to format it, click Cancel.
  3. Back up the whole FM-1 with M-Flasher and keep the file: it brings your FM-1 back exactly as it is today.
  4. Install the bootloader with fm1-uboot.boot. Only the boot area is written: your current firmware stays.
  5. Switch the FM-1 off and on while holding PLAY: the menu appears.
Alternative · FM-1 on M-VAVE's own firmware

With M-VAVE's M-UPGRADE app

Download fm1-uboot.fwsc from the latest m-bootloader release, open it in M-UPGRADE (close other MIDI apps first) and start the upgrade. It writes only the bootloader. If in doubt, prefer M-Flasher, which also makes the full backup.

Good to know
  • Keep the power on while the bootloader is written.
  • FM-1s sold since fall 2026 have another flash chip, the UCUN UC25HQ80 (JEDEC 0xB36014). m-bootloader has not been run on it yet, and one such unit did not start after it was installed. Use M-Flasher 0.9.1 or newer, which warns you, and make its backup first. SLOOP 3 accepts this chip, but it has not been tried on one yet either.
  • M-VAVE's official updates put their own bootloader back: after one, do this step again.
Step 3 of 5

Connect your FM-1

Start the FM-1 in MIDI MODE, plug it in, and let this page find it.

  1. Switch the FM-1 off, then on while holding PLAY.
  2. In the menu, choose MIDI MODE with OCT- / OCT+, then press PLAY. The screen asks you to connect USB.
  3. Plug it into the computer with the USB cable, then click Connect. When the browser asks to control your MIDI devices, click Allow.

Technical details

Help

The answers to what can go wrong. Still stuck? Ask in the issues.

“No FM-1 found”
Check that the FM-1 shows MIDI MODE (step 3), and that the cable carries data: try another cable or USB port, without a hub. Close other apps that use MIDI (M-UPGRADE, editors, music software), then click Connect again.
“The FM-1 is running a firmware”
It started SLOOP, or another firmware, instead of the menu. Switch it off, then on while holding PLAY about a second. If no menu appears, m-bootloader isn't installed yet (step 2).
The install stopped halfway
Nothing is lost. Nothing is erased before the whole package has been checked. If it stops while writing, m-bootloader sees an incomplete firmware at the next start and opens its menu by itself: reload this page and install again.
The browser never asks about MIDI
Use Chrome or Edge. Click the icon left of the address, open the site settings, and allow MIDI devices. Then reload the page.
The backup stops
Some m-bootloader versions don't answer reads. Make the backup with M-Flasher instead (step 2), then tick “I already have a full backup”.
SLOOP 3 doesn't start, or starts badly
Hold OCT- while switching on: RESCUE. PLAY starts with an empty project (your saved project is kept). Or hold PLAY for m-bootloader's menu and install again. Then tell us what the screen showed.
Going back to SLOOP 2.8 or M-VAVE's firmware
Restore your backup with M-Flasher (hold REC while switching on for download mode). It brings the FM-1 back exactly as it was when you made it. Projects made with SLOOP 3 since then are not in it: save them as files with the web editor first.
Updating SLOOP 3 later
Open this page again: steps 3 to 5, about a minute. Your project and your sounds stay.
